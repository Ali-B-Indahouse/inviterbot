# 🤖 Telegram Бот для регистрации на мероприятие

Бот для регистрации участников на мероприятия с разделением ролей, генерацией QR-кодов и интеграцией с Google Sheets.

---

## 📋 Возможности

- ✅ **Регистрация участников** — по одному или массово
- ✅ **Генерация QR-кодов** — с именем участника и логотипом
- ✅ **Сканер QR-кодов** — отметка входа по фото
- ✅ **Ролевая модель** — мастер, регистратор, сканер
- ✅ **Лимиты регистраций** — у каждого регистратора свой лимит
- ✅ **Статистика** — персонализированная под каждую роль
- ✅ **Кнопки** — всё управление через удобное меню
- ✅ **Google Sheets** — все данные хранятся в таблице

---
